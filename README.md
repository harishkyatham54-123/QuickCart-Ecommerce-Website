# QuickCart E-Commerce Website

## Overview
QuickCart is a responsive e-commerce web application developed using HTML, CSS, and JavaScript.

## Features
- Product Listing
- Add to Cart
- Remove from Cart
- Wishlist Functionality
- Dynamic Cart Count
- Total Price Calculation
- Responsive UI Design

## Technologies Used
- HTML5
- CSS3
- JavaScript
